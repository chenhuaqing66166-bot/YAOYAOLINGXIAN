# 800 驾驶体验

一个私人网页小游戏原型：第一视角驾驶、连续油门和刹车、道路随车速移动，以及 70 km/h 触发踏板断裂和胶水修复的虚构玩法。

## 运行

直接打开 `index.html` 即可试玩。也可以在这个目录启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。

## 操作

- 长按油门或 `W` / `↑`：平滑加速
- 长按刹车或 `S` / `↓` / 空格：平滑减速
- 70 km/h 后踩刹车：触发游戏中的踏板断裂
- 长按胶水或 `G`：修复踏板
- `P`：暂停

画面参考豪华车型内饰质感，已移除真实品牌标识，仅保留 `800` 作为游戏标识。断裂和修复机制是虚构的游戏设定，不代表真实车辆安全结论。
